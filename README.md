# Shadowrun 2E: Corporate Security Handbook

Content from the *Corporate Security Handbook* (FASA 7118) for the
[Shadowrun 2nd Edition system](https://github.com/futurekill/sr2e-foundryvtt) for Foundry VTT v13: security gear, fat bacteria and the BacteriTech netgun, Ares VTOLs and drones, security personnel and archetypes, the Goose totem and new adept powers, and GM reference journals.

Requires sr2e 0.102.0 or later, whose astral walls and fat-bacteria zones the
fat-bacteria gear is built to use.

For personal table use with a copy of the book you own.
