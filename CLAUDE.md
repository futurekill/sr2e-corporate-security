# Corporate Security Handbook module — development notes

A FoundryVTT **V13** content module packaging the *Corporate Security Handbook*
(FASA 7118) for the **sr2e** system. Optional by design: a GM enables it per world.
Requires sr2e ≥ 0.102.0, which ships the mechanics this content uses (astral walls,
projection forms, fat-bacteria zones; see the system's docs/PLAN-astral-barriers.md).
The approved plan is docs/PLAN.md (4 Codex rounds → APPROVED).

## Source
`../Shadowrun 2e - Corporate Security Handbook {FASA7118}.pdf` is **image-only**
(no text layer): every value is read from rendered pages
(`pdftoppm -r 170`). The colour plates are counted in the folios, so the PDF-to-book
offset changes: the catalog runs book p.67–73, then p.81–93; GM Information
p.94–105 (PDF = book + 9 there). **Cite BOOK pages.** `_work/` and
`../sr2e-corporate-security-work/` hold renders and are never committed.

## Build
`packs-src/` is the source of truth, generated by:
- `tools/gen-items.mjs`: weapons, ammo, gear, adept powers, vehicle options;
- `tools/gen-actors.mjs`: personnel, archetypes, vehicles, from `tools/data/personnel.json`;
- `tools/gen-journals.mjs`: GM reference, original paraphrase only.

`npm run generate`, then `npm run build-packs` (stop Foundry first: LevelDB locks).
Generators keep an existing `img`, and actors pick up portraits by file, so
re-running never un-wires art. `npm run validate` checks every pack by the document
type module.json declares.

## Modelling decisions (from the plan)
- **Mechanics live in the system; this module is data.** The FAB-NG netgun ships
  with a manual procedure (notes + journal); automating it is a separate system plan.
- **Gamma-scopolamine:** the drug engine applies all item effects at dosing, so the
  truth-serum aftermath is a manual GM step, not an item effect.
- **Enhanced Perception** is three tier items, because the system prices a power as
  cost × level.
- **Personnel and archetypes are `npc` actors** carrying the printed values exactly
  (Reaction `mod` lands the derived value on the printed number). Spells that exist
  in the core spell compendium are embedded; Grimoire II spells are listed in the bio.
- **Facility hardware** (CCSS, control centers, drone storage) is reference text,
  not items.
